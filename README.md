## Overview

**AI_Dont_Talk_Shit** is a high-performance, platform-agnostic system directive and Agent Skill designed to strip away AI conversational overhead, enforce immediate conclusion delivery, and maximize information density. 

> *"Eliminate all conversational filler, preambles, platitudes, and corporate padding. Deliver raw, dense, highly structured, and actionable substance immediately."*

---

## Key Features

<table width="100%">
  <tr>
    <td width="50%" valign="top">
      <h3>🎯 Conclusion First</h3>
      <p>Forces models to state the direct answer, primary solution, or core output in the very opening sentence—zero introductory buildup.</p>
    </td>
    <td width="50%" valign="top">
      <h3>🚫 Zero Fluff & Platitudes</h3>
      <p>Strictly bans canned conversational filler like <em>"Sure, I can help with that"</em>, <em>"That's a great question"</em>, or unnecessary safety disclaimers.</p>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>⚡ Signal-to-Noise Max</h3>
      <p>Prioritizes technical markdown, structured tables, and compact code blocks over flowing paragraphs and conversational wrap-ups.</p>
    </td>
    <td width="50%" valign="top">
      <h3>🌐 Platform-Agnostic</h3>
      <p>Compatible across custom instructions, system prompts, Claude Projects, Ollama local models, and agent skill runners.</p>
    </td>
  </tr>
</table>
